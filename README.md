# MCSP for Mac

Downloads for **MCSP for Mac** — the [MC Service Producer](https://mcserviceproducer.com) countdown
in your menu bar, desktop widgets, cue alerts, and the MCSP web app in a window (the dashboard,
or a no-sign-in producer view for a producer ID).

This repository holds release builds only.

## Install

1. Download **MCSP.dmg** from the [latest release](https://github.com/anthonydavis94/mcsp-mac-releases/releases/latest).
2. Open it and drag **MCSP** into **Applications**.
3. Open MCSP from Applications. Enter a producer ID (for example `GC`) for the producer view,
   or open the dashboard and sign in.

Requires macOS 14 Sonoma or later.

### Preview builds

Builds marked **(preview)** aren't signed by Apple yet. The first time you open one, macOS
blocks it: click **Done**, open **System Settings › Privacy & Security**, find
*"MCSP" was blocked…* and click **Open Anyway**. You only do this once.

## Updates

MCSP checks for updates on its own every few hours, and from **MCSP › Check for Updates…**.
Each update is verified before it's installed; preview copies update to the signed releases
when they're out.
